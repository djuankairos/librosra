## Brand Identity (from `assets/Reinita Amarilla Brand Guidelines 2025.pdf`)

### Color Palette

| Role | Name | Hex |
|------|------|-----|
| Primary | Amarillo Principal | `#F5C800` |
| Primary light | Amarillo Claro | `#FDE96A` |
| Accent / CTAs | Naranja Acento | `#F07020` |
| Hover / variant | Naranja Claro | `#F9A05A` |
| Logo only | Azul Logo | `#2E9CCA` |
| Text / dark bg | Negro Profundo | `#1A1A1A` |
| Eco / positive | Verde Naturaleza | `#5AAB4B` |
| Page bg / cards | Crema Fondo | `#FFF8E7` |

`#2E9CCA` is **logo-exclusive** — do not use it freely in UI. All text on brand backgrounds must meet WCAG AA contrast (4.5:1 minimum).

Recommended combinations: White + Black (standard), Black + Yellow (premium/hero), White + Orange (CTAs), Cream + Orange (warm/reading).

### Typography (Google Fonts — do not substitute system fonts)

| Role | Family | Weights | Usage |
|------|--------|---------|-------|
| Display | Playfair Display | 700, 900 | H1, H2, publication names |
| Technical | Space Mono | 400, 700 | Labels, prices, categories, codes |
| Body | Lato | 300, 400, 700, 900 | Paragraphs, descriptions, buttons, UI |

### Logo Usage

- Minimum size: 60px digital; use 100px for web, 160px for header, 200px for hero
- Clear space: minimum ½ the logo width on all sides
- Approved backgrounds: White, Cream (`#FFF8E7`), Black, Yellow (`#F5C800`)
- Never distort, recolor, add shadows/effects, or crop any element

### UI Patterns (from brand application examples)

- **Buttons**: Primary (black fill, white text), Secondary (orange fill), Outline (black border)
- **Badges**: NEW, BEST PRICE, year (e.g. 2025), EN OFERTA — use category colors for category badges
- **Prices**: Display with `₡` symbol using Space Mono; show strikethrough original + highlighted sale price + savings badge when discounted
- **Book cards**: Category badge (colored) + title (Playfair Display) + author (italic Lato) + description + metadata labels (Space Mono) + price
